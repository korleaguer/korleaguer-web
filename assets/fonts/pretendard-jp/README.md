# Pretendard JP (한자 대체 글꼴)

공유 미리보기 그림(og 이미지)에서 Pretendard에 없는 한자를 그리려고 쓰는 글꼴이다(src/lib/og.tsx).
npm 패키지 `pretendard-jp@1.3.9`(https://github.com/orioncactus/pretendard)에서 Bold·ExtraBold 두 파일만 **고치지 않고** 그대로 복사했다.
라이선스는 SIL OFL 1.1(LICENSE.txt). 예약 글꼴 이름이 'Pretendard JP'라서 서브셋 같은 수정본은 같은 이름으로 배포할 수 없어 원본 그대로 둔다.
패키지를 통째로 설치하면 Next가 글꼴 폴더 전체(약 91MB)를 운영 이미지에 넣어서 파일만 두었다.
